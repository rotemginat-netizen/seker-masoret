# סקר מסורת – הוראות הקמה

- **דף חניכים** (`/`) – עונים מהטלפון, שתי שאלות רב-בחירה.
- **דף מדריכה** (`/admin`) – גרפים חיים, קוד QR לכניסה, פתיחה/סגירה של ההצבעה, "סבב חדש" לקבוצה הבאה, והשוואה לתוצאות הארציות.

---

## שלב 1 – Firebase (כ-5 דקות)

1. נכנסים ל-https://console.firebase.google.com ← **Create a project** (אפשר לכבות Google Analytics).
2. בתפריט הצד: **Build → Firestore Database → Create database** ← לבחור מיקום (למשל `eur3`) ← **Start in production mode**.
3. בלשונית **Rules** של Firestore: מוחקים הכול, מדביקים את התוכן של הקובץ `firestore.rules` ולוחצים **Publish**.
4. גלגל השיניים ⚙️ ← **Project settings** ← למטה ב-**Your apps** לוחצים על `</>` (Web) ← נותנים שם ← **Register app**.
5. מעתיקים את הערכים מתוך `firebaseConfig` אל הקובץ `firebase-config.js` (במקום `PASTE_HERE`).

## שלב 2 – העלאה ל-Vercel

**דרך א' – בלי להתקין כלום (דרך GitHub):**
1. ב-https://github.com/new יוצרים מאגר חדש (אפשר Private).
2. לוחצים **uploading an existing file**, גוררים את כל הקבצים מהתיקייה ← **Commit changes**.
3. ב-https://vercel.com/new מתחברים עם GitHub, בוחרים את המאגר ← **Deploy** (בלי לשנות הגדרות).

**דרך ב' – משורת הפקודה** (אם מותקן Node.js):
```
cd survey-app
npx vercel --prod
```

מקבלים כתובת כמו `https://seker-masoret.vercel.app`:
- חניכים: `https://seker-masoret.vercel.app`
- מדריכה: `https://seker-masoret.vercel.app/admin`

## בזמן הפעולה

1. פותחים את `/admin` על המקרן – ה-QR מוביל את החניכים לסקר.
2. הגרפים מתעדכנים עם כל תשובה.
3. **סגירת הצבעה** – עוצר קבלת תשובות חדשות.
4. **הצגת תוצאות ארציות** – מוסיף פס אפור עם תוצאות הציבור הישראלי להשוואה (כדאי לחשוף אחרי שכולם ענו).
5. **סבב חדש** – מאפס את הגרפים לקבוצה הבאה (התשובות הקודמות נשארות במסד הנתונים).

## לשנות שאלות

כל השאלות והתשובות נמצאות בקובץ `questions.js`. אם מוסיפים אפשרויות – צריך לעדכן גם את המספרים `12` ו-`6` ב-`firestore.rules`.

## הערת אבטחה

דף המדריכה לא מוגן בסיסמה – מי שמכיר את הכתובת `/admin` יכול לפתוח/לסגור הצבעה או להתחיל סבב חדש. התשובות עצמן אף פעם לא ניתנות למחיקה או לשינוי. לפעילות בקבוצה זה מספיק; אם צריך יותר – אפשר להוסיף התחברות מדריכה עם Firebase Auth.
